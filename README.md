# Profile Builder

A beginner-friendly Python script that collects basic user information through the command line and displays a formatted summary.

## Overview

This script demonstrates fundamental Python concepts such as user input, variable assignment, and formatted output. It prompts the user for four pieces of information and then displays them in a clean, readable format.

## Features

- Collects user input interactively via the terminal
- Stores responses in variables
- Displays a structured summary once all inputs are collected

## Information Collected

| Field       | Description                     |
|-------------|----------------------------------|
| Name        | User's full name                |
| Gender      | User's specified gender         |
| Profession  | User's current occupation       |
| Age         | User's age                      |

## Requirements

- Python 3.x

## Usage

1. Clone or download this repository
2. Navigate to the project directory
3. Run the script:
   ```bash
   python profile_builder.py
   ```
4. Respond to each prompt as it appears, pressing **Enter** after each response

## Example

**Input:**
```
What's your name? : Anushka
Specify your gender: Female
What do you do? : Developer
How old are you? : 19
```

**Output:**
```
Name: Anushka
Gender: Female
Profession: Developer
Age: 19
```

## Concepts Demonstrated

- `input()` — capturing user input from the command line
- Variables — storing and referencing collected data
- `print()` — formatting and displaying output
